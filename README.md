# Purple Air Monitoring Dashboard

This project aims to provide a platform for the visualization of the air quality data
retrieved on the Pennsylvania State University’s Harrisburg campus through PurpleAir
indoor sensors. It mainly involves developing a web-based dashboard to display indoor
air quality data collected from the sensors. The system will allow authorized users to
view current and historical air quality measurements through an interactive interface.

- Node.js LTS 24.1.0
- React 19.3.0
- JDK 21.0.3

### Quick Start


Run in terminal this command to install the packages:

```bash
npm install
```

Then run this command to start your local server:

```bash
npm start
```
